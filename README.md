# T101

T101 是面向《英雄联盟》用户的桌面辅助产品，基于 Tauri 2 构建。产品提供一个可与 League 客户端或游戏窗口同步位置的侧边窗口，帮助用户在桌面上保持辅助窗口与目标窗口并行使用。

当前版本仅提供 Windows Tauri 2 桌面端，不提供 Web 面板或浏览器服务。

## 核心功能

- 自动识别 League 客户端和游戏窗口，并将辅助窗口跟随到目标窗口右侧。
- 窗口跟随过程中不抢占焦点，不改变目标窗口的层级。
- 游戏窗口处于全屏或最大化状态时，仅调整辅助窗口位置，不移动或缩放游戏窗口。
- `F9`：调整游戏窗口与辅助窗口的布局。
- `F10`：暂停或恢复窗口跟随。
- `Ctrl+Alt+F12`：退出产品。

## 使用要求

- Windows 系统
- Rust stable
- Windows 工具链
- WebView2 Runtime

Windows 用户构建后，可运行：

```powershell
npm run panel
```
